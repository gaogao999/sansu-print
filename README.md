# 算数プリントメーカー

小学3年〜中学1年の算数・数学プリントを A4 一枚ぶん作って、そのまま印刷するページ。
**計算・図形（図つき）・文章題**の37単元、**日本語／English**、**学年ミックス・単元ミックス**。

👉 **https://gaogao999.github.io/sansu-print/**

`index.html` の1ファイルだけで動く。ビルドも通信もいらない
（Google Fonts だけ読みにいくが、無くても表示される）。ダウンロードしてローカルで開いてもよい。

## つかいかた

1. **学年**をえらぶ（いくつでも＝学年ミックス）
2. **ぶんや**（計算／図形／文章題）でしぼる
3. **単元**をクリック＝その単元だけ。`まぜて えらぶ` を押すとクリックで足していける。`ぜんぶ えらぶ` で全部
4. **ことば**で日本語／English を切りかえ（問題文・名前欄・見出しがまるごと変わる）
5. `A4で 印刷する` → 1まいめが問題、2まいめがこたえ（朱色）

| ボタン | すること |
|---|---|
| `ランダムに 作る` | えらんだ学年・ぶんやの中から**単元を2〜5個おまかせで選び直して**1枚作る |
| `べつの問題に する` | 単元も設定もそのままで、**問題だけ**入れかえる |

- 問題は **プリント No.** から作るので、同じ番号なら何度でも同じ問題が出る
- 問題の数は**用紙が埋まるまで自動で増減**する。`問題の数` を自分で選ぶと、その数を守る
  （`ランダムに 作る` でおまかせに戻る）
- 設定はブラウザに残る

## 単元（37）

**計算** … 整数の四則（よこ式・ひっ算・100マス）／**虫食い算（□をもとめる）**／四則混合（かっこ）／がい数／倍数と約数／
小数／分数／単位のかんさん／割合・百分率／比／文字と式／比例と反比例／正負の数／一次方程式

**図形**（図つき） … 円と球／まわりの長さ／長方形・正方形の面積／角の大きさ／
三角形・四角形の面積／三角形・四角形の角／円周／直方体の体積／円の面積／角柱・円柱の体積／
平行線と角／おうぎ形／円柱・円すいの体積

図形は**逆向きの問い**も出る。「面積とたて→よこ」「面積→正方形の1辺」「まわりの長さとたて→よこ」
「面積とそこへん→高さ」「円周→直径」「面積→半径」「体積と底面→高さ」。
図では わからない ところが `?` になる。

**文章題**（式・こたえ欄つき） … 四則の文章題／時こくと時間／単位量あたり／平均／速さ／
割合／分数／比／場合の数／方程式の文章題

文章題は単元ごとに**3〜10通りの型**を順ぐりに出すので、1枚の中で同じ言い回しが続かない。
たとえば四則の文章題は あわせて・もらう・のこり・ちがい・倍・等分・あまり・おつり、
小4からは2だんかいの問題も。登場する名前14人・もの14種。

## 学年の わりあて

単元の学年は学習指導要領に合わせている（分数の加減は同分母が小4・異分母が小5、
文字と式は小6が「式の値・文字で表す」まで、同類項や分配法則は中1、
比例・反比例は小6から、円の面積は小6、おうぎ形と円すいは中1）。
学年をえらぶと、その学年で使える計算だけが光る（例：小4・小5の分数は ＋ − だけ）。
けた数などを自分で変えれば範囲外の問題も作れる。

## 直しかた

`index.html` を直接ひらいて直す。`main` に push すると GitHub Pages に反映される
（Settings → Pages のソースは **Deploy from a branch / main / (root)**。ビルドは無い）。

- 見た目 … 先頭の `<style>`。用紙まわりは `.paper` 以下
- 単元の追加 … `UNITS` に1行足し、`u◯◯(rand,o)` を書く。
  返す形は `{kind:"calc"|"fig"|"word", key, ex/q, eq, ans, fig, long}`
- 図 … `svg()` `fitBox()` `vdim()` `arcPath()` で描いている
- 1枚に入る数と行間 … `layoutSheets()`（用紙の高さを測って決めている）
