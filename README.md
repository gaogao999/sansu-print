# 算数プリントメーカー

小学3年〜中学1年の算数・数学プリントを A4 一枚ぶん作って、そのまま印刷するページ。
**計算・図形（図つき）・文章題**の37単元、**日本語／English**、**学年ミックス・単元ミックス**。

👉 **https://gaogao999.github.io/sansu-print/**

`index.html` の1ファイルだけで動く。ビルドも通信もいらない
（Google Fonts だけ読みにいくが、無くても表示される）。ダウンロードしてローカルで開いてもよい。

## つかいかた

1. **学年**をえらぶ（いくつでも＝学年ミックス）
2. **ぶんや**（計算／図形／文章題）でしぼる
3. **単元**をクリック＝その単元だけ。`まぜて えらぶ` を押すとクリックで足していける。`ぜんぶ えらぶ` で全部
4. **ことば**で日本語／English を切りかえ（問題文・名前欄・見出しがまるごと変わる）
5. `A4で 印刷する` → **1まい**だけ出る（こたえのプリントは出ない）
6. こたえは紙の**右上の QR**に入っている。スマホのカメラで写すと
   さいてん画面がひらいて、こたえがならぶ

- `べつの問題に する` … 単元も設定もそのままで、**問題だけ**入れかえる
- 問題は **プリント No.** から作るので、同じ番号なら何度でも同じ問題が出る
- `問題の数` は **`おまかせ`** で用紙が埋まるまで自動で増減する（いま何問になったかは
  `おまかせ（30問）` のように選択肢に出る）。数を選べばその数を守り、`おまかせ` に戻せる
- `1行の数` を自分で選んでも、**式が横に入りきらなければ列を自動で減らす**
  （描いてから測って判断するので、字数の見当ではなく実際のはみ出しで決まる）
- 設定はブラウザに残る
- `くり上がり・くり下がり` は **どちらも／ない ものだけ／ある ものだけ** の3つ。
  採点の見立てから「くり上がりだけ 20問」に飛べるのはこのため

## 単元（37）

**計算** … 整数の四則（よこ式・ひっ算・100マス）／**虫食い算（□をもとめる）**／四則混合（かっこ）／がい数／倍数と約数／
小数／分数／単位のかんさん／割合・百分率／比／文字と式／比例と反比例／正負の数／一次方程式

**図形**（図つき） … 円と球／まわりの長さ／長方形・正方形の面積／角の大きさ／
三角形・四角形の面積／三角形・四角形の角／円周／直方体の体積／円の面積／角柱・円柱の体積／
平行線と角／おうぎ形／円柱・円すいの体積

図形は**逆向きの問い**も出る。「面積とたて→よこ」「面積→正方形の1辺」「まわりの長さとたて→よこ」
「面積とそこへん→高さ」「円周→直径」「面積→半径」「体積と底面→高さ」。
図では わからない ところが `?` になる。

**文章題**（式・こたえ欄つき） … 四則の文章題／時こくと時間／単位量あたり／平均／速さ／
割合／分数／比／場合の数／方程式の文章題

文章題は単元ごとに**3〜10通りの型**を順ぐりに出すので、1枚の中で同じ言い回しが続かない。
たとえば四則の文章題は あわせて・もらう・のこり・ちがい・倍・等分・あまり・おつり、
小4からは2だんかいの問題も。登場する名前14人・もの14種。

### まだ入れていない単元

指導要領にはあるが、この道具にはまだ無いもの。

- 小3 大きい数（万の位）／二等辺三角形・正三角形
- 小4 億・兆／平行と垂直・四角形の性質／直方体と立方体
- 小5 合同／正多角形
- 小6 拡大図・縮図／線対称・点対称／代表値
- 中1 素因数分解／立体の表面積

紙の1枚では出しにくいもの（そろばん、表・棒グラフ・折れ線・円グラフ・
帯グラフ、コンパスの作図、図形の移動、度数分布・相対度数）は入れない。

## 問題数の 詰めかた（おまかせ）

用紙に入るだけ入れる。手順は「多めに入れて、入らなければきっちり減らす」。

1. `layoutSheets()` が実際の DOM を測り、**入る問題数（cap）**と**残りの余白**を返す
2. 余白がいちばん低い行 1つ分以上あれば、その分だけ増やして描き直す
3. 見つもりが 0 でも **最後にもう1行だけ試す**（行の高さは中身で変わるため）。
   入らなければ 4 が戻す
4. はみ出したら cap まで減らす。**選択肢の数（10問・15問…）に丸めない**
   ─ 丸めると数問ぶん無駄になる
5. 式が横に入らなければ列を1つ減らして 1 からやり直す

止まるのは「1行増やすと必ずはみ出す」状態なので、原理的にこれ以上は入らない。

## 直しかた

`index.html` を直接ひらいて直す。`main` に push すると GitHub Pages に反映される
（Settings → Pages のソースは **Deploy from a branch / main / (root)**。ビルドは無い）。

- 見た目 … 先頭の `<style>`。用紙まわりは `.paper` 以下
- 単元の追加 … `UNITS` に1行足し、`u◯◯(rand,o)` を書く。
  返す形は `{kind:"calc"|"fig"|"word", key, ex/q, eq, ans, fig, long}`
- 図 … `svg()` `fitBox()` `vdim()` `arcPath()` で描いている
- 1枚に入る数と行間 … `layoutSheets()`（用紙の高さを測って決めている）

# さいてん（採点と記録）

印刷したプリントに丸をつけて、**単元ごとの現在地**を出す画面。
👉 **https://gaogao999.github.io/sansu-print/saiten.html**

## しくみ

こたえは**紙の QR**に入っている。プリントの右上の QR をスマホのカメラで写すと、
さいてん画面がひらいて、そのプリントのこたえがならぶ。打ちこむ必要はない。

同じ端末で印刷したときは `localStorage` にも残るので、QR を写さなくても
プリントの一覧から選べる。**紙のほうが本もの**で、端末の記録が消えても紙の QR から読みなおせる。

### QR の 大きさは 何で 決まるか

こたえの量＝問題の数で決まる。実測（1マス 0.36mm 換算）:

| 問題数 | 小3 整数 | 小5 小数 | 小6 分数 |
|---|---|---|---|
| 6問 | 18mm | 18mm | 18mm |
| 20問 | 20mm | 21mm | 22mm |
| 40問 | 22mm | 24mm | 25mm |
| 60問 | 25mm | 28mm | 30mm |

**段は6〜10問ごとに1〜2mm**で、崖はない。だから「QRを小さくするために問題を減らす」のは
割に合わない（60問→40問で 30→25mm、5mm しか変わらない）。
大きさと書き方はこの表のとおり自動で決まるので、使う側が気にする必要はない。

詰め方はほぼ限界まで来ている。こたえを大きな整数にして QR の数字モード（1字3.33ビット）で
送る手も試したが **−4マス（1〜2mm）** にしかならず、BigInt と別形式を増やす価値はなかった。

### QR の中身

`https://…/saiten.html#s=3*<No.>*<型のならび>*<問ごとの番号>*<こたえ!こたえ!…>*<むずかしさ>`

型のならびは `int.3dr-int.3d` のように **単元・学年・演算・型の印** をまとめたもの。
問ごとの番号がそれを指す。これで採点画面が「くり上がりのある問題だけ落ちている」まで見られる。

- 通信はしない。**URL のフラグメントに全部入っている**ので、開いた先で組み立てるだけ
- 短く書くための決めごと … `/`→`~`、`あまり`→`r`、スペース→`_`、
  同じ文字のならびは1文字、文章題・図形の型は2文字のコード（`TIDC`。index と saiten で同じ表）
- **こたえが数字と記号だけの紙は、大文字だけの書き方（`#a=`）に切りかえる。**
  QR は大文字・数字・記号だけなら1字5.5ビット（ふつうの文字は8ビット）で入るので、
  同じ中身でもマス目が1割ほど減り、1マスが大きくなって目が粗くなる。
  「cm」「円」が入る図形・文章題は大文字にすると戻せないので対象外。
  書き方は3通り（そのまま `#s=` / base64 `#b=` / 大文字 `#a=`）作って、
  **マス目がいちばん少ないものを選ぶ**ので、今までより悪くなることはない
- 日本語が多くて base64 のほうが短いときは `#b=` に切りかわる
- **QR の大きさは中身に合わせて変える**（24〜34mm）。1マスが 0.42mm を下回ると
  家庭用プリンタでにじんで読めなくなるため
- 100マスは `2*<No.>*<演算>*<よこ>*<たて>` だけ送って、こたえは読んだ先で作る
- 前に刷った `1*…` の QR も読める（互換）
- 読む側は知らない単元・範囲外の学年・こわれた文字列をすべて捨てる。
  こたえは `esc()` してから出す（他人の作った QR を写しても安全）

1. **さいてん** … プリントをえらぶ → 名前を入れる → **まちがえた問題だけタップ**（はじめは全部○）
   → `記録する`。写真は任意で添付できる（記録に残すだけ。自動採点はしない）
2. **きろく** … つけたプリントの一覧。点数・写真・日付
3. **分析** … **見立て**、計算の種類ごと、学年ごと、単元ごとの正答率、最近の点数

### 現在地（レベル）の 決めかた

学年ごとに **正答率と、その学年の単元をいくつ触ったか（カバー）** の2つで判定する。
点だけで「通過」とは言わない。2単元90%は通過ではなく「まだ触っていないところが多い」だけ。

| 状態 | 条件 |
|---|---|
| **通過** | 12問以上・85%以上・その学年の単元の **4割以上**（最低3単元）を3問以上といた |
| **あと少し** | 70%以上 |
| **練習中** | 70%未満 |
| **ためし中** | 12問未満、または単元が2つ未満、または点はよくてもカバーが足りない |
| **まだ** | 1問もといていない |

**現在地** ＝ データがあって「通過」していない、いちばん下の学年。全部通過ならその上。
画面には大きく「小4 の とちゅう」と出し、下に学年のはしご（％・問題数・◯/◯単元）を並べる。
まだ触っていない単元は名前を挙げて「ここをためすと現在地がはっきりします」と出す。

### 見立ての決めかた

**正答率だけでは診断にならない。**「分数が55%」は症状であって原因ではない。
そこで問題を作るときに、1問ごとに**型の印**を残しておき、採点結果をその型で割って見る。

| 印 | 意味 | 単元 |
|---|---|---|
| `c` | くり上がり・くり下がりがある | 整数・虫食い・小数 |
| `z` | 0から借りる（空位をまたぐ） | 整数・虫食い |
| `r` | あまりが出る | 整数・虫食い |
| `w` | かける数・わる数が2けた（小数×小数） | 整数・虫食い・小数 |
| `k` `n` | 小数点の位がそろわない／末尾の0を消す | 小数 |
| `t` `y` `m` | 通分／約分／帯分数になおす | 分数 |
| `L` `R` | □が左（逆算）／右 | 虫食い |
| `p` `d` | かっこ／÷がまざる | 四則混合 |
| `g` `b` | 答えがマイナス／うしろがマイナス | 正負の数 |

文章題と図形は、印のかわりに**型そのもの**（「時間をもとめる」「面積から高さをもとめる」など66種）を使う。

見立てはこの順に出す。**土台が先**、土台どうしは整数→小数→分数（前提の順）。

| 順 | 見るところ | 出る言い方 |
|---|---|---|
| 1 | 整数の ＋−×÷ のうち1つだけ落ちていないか | 「整数のわり算が42%、ほかは92%」 |
| 2a | にがて単元の**前提**が実際に崩れていないか | 「整数の四則から。分数はそのあと」 |
| 2b | 単元の中の**型で割れていないか** | 「分数 ― 通分で止まっている（通分あり23%／なし87%）」 |
| 2c | 前提を**まだといていない**なら先にためす | 「倍数と約数を先にためす」 |
| 2d | 型でも割れず土台もとれている | 「やり方は分かっている。数をこなす／見直しの段階」 |
| 3 | **後半で落ちていないか**（集中・時間） | 「前半94%、後半64%」 |
| 4 | 60〜70%の土台単元 | 「あとひと押し」 |
| 5 | けたが増えると落ちるか（プリントの設定でくらべる） | 「2けたなら94%、3けたで56%」 |
| 6 | のびている単元 | 「33% → 92%。手をゆるめてよい」 |
| 7 | つまずきがなければ、まだの単元をすすめる | 基礎に近い順に |

それぞれ **見えたこと（数）→ どう読むか → やること** の3つで書く。

**判断の決めごと**

- 6問以上といて **70%未満＝土台があやしい**、**60%未満＝にがて**、**85%以上＝型は分かっている**
- 型で2つに割ってくらべるのは、**両がわ4問以上**あるときだけ。差が**25ポイント以上**で「ここで落ちている」と言う
- **12問に満たない単元には「まだ少ないのでめやす」**と付ける。ぜんぶで12問未満なら見立てそのものを出さない
- 演算べつの集計は**整数と虫食い算だけ**。分数の×などを混ぜると、計算の力と単元の理解がごちゃまぜになるため
- 「後半で落ちる」は**同じ型どうしで前半後半をくらべ、型ごとの差を重みつきでならす**。
  後半に難しい問題がかたまっているだけのものを「集中が切れた」と読みまちがえないため
- 手当てをすすめた単元は「のびています」と**ほめない**（ちぐはぐになる）

**見立てから飛ぶリンクは、その型だけを出す。**

| 見立て | リンク |
|---|---|
| くり上がりで落ちる | `?g=3&u=int&n=20&cy=only` |
| 通分で落ちる | `?g=5&u=frac&n=20&fd=diff` |
| 2けたでわるところで落ちる | `?g=4&u=int&n=20&db=2` |
| あまりのあるわり算 | `?g=4&u=int&o=d&da=2&db=1&dm=rem&n=20` |

単元を指定したリンクは「処方」なので、**前につかったむずかしさの設定はいったん既定にもどす**。
そうしないと、前に「くり上がりなし」にしていた人には、くり上がりのない紙が出てしまう。

## 決めごと

- **写真から自動で採点はしない**。手書きの「1と1/6」「あまり2」「8000 m」などを
  読み違えると採点が信用できなくなるため、○×は人がつける（実際は3〜5タップで終わる）
- **にがて** … 5問以上といて正答率60%未満の単元
- 単元は**学年ごとに分けて**数える（同じ「整数の四則」でも小4と小5は別もの）
- 記録はこの端末の中だけ。ほかの端末とは共有されない

## データを まもる

ブラウザのおぼえたものは**消えることがある**（空きが足りない、しばらく使わない、
iOS のサイトデータ削除など）。そこで:

- `きろく` タブの **`ファイルに 書き出す`** … 記録・名前・プリントを1つの JSON に落とす。
  これが本ものの置き場所。端末をかえるときもこれを持っていく
- **`ファイルから 読みこむ`** … **足し算だけ**する。同じ id のものは入れない、
  今ある記録は消さない・上書きしない。何度読んでも増えない
- 最後に書き出した日と、そのあとに増えた件数を出す。10件たまると枠の色をかえてうながす
- `navigator.storage.persist()` を頼んでおく（対応ブラウザでは消えにくくなる）
- 記録は400件まで。あふれたら古いものから。空きが足りないときは**写真だけ**先に落とす
- そもそも**こたえは紙の QR に入っている**ので、端末の記録が飛んでも採点はやりなおせる
- Claude のアーティファクト版で印刷した分は、端末の記録には残らない（置き場所がちがう）。
  ただし**紙の QR は公開サイトのさいてん画面を指す**ので、写せばそのまま採点できる

## 検証

### 設定の 組み合わせは いくつ あるか

| 数えかた | 通り |
|---|---|
| 単元1つの紙・**問題の中身が変わる設定**（単元63×演算の選び方×けた×くり上がり×あまり×分母×かっこ×式の形×ことば） | **8,258** |
| 単元1つの紙・紙の見た目まで含む（＋かたち×問題数×列×名前らん） | 1,158,320 |
| ＋プリント番号（1〜99999） | 約 1,158億 |
| まぜて選ぶ紙・単元の選び方だけで | 2³⁷ − 1 ＝ 約 1,374億 |
| ぜんぶ | 約 **2.4×10¹⁸** |

尽くせるのは1段目だけなので、**そこは全部**通した。まぜて選ぶ紙は1万枚のでたらめ抽出で、

見つけて直したもの（このラウンド）:

- QRの型番号が **36種類を超えると別の単元に化けていた**（こたえが違う単元の記録になる）
- おつりの文章題で **代金が出したお金を超えて答えがマイナス**になることがあった
- 「1行の数」を3列に固定すると、**ひっ算のマスが紙から38mm飛び出す**／文章題が1列に落ちて下に17mmはみ出す
- 問題数の選択肢が10問からしか無く、**大きな図の紙で「入る数まで減らす」ができずはみ出したまま**になっていた
- 学年の見立てが「同じ型どうし」で比べておらず、**後半に難しい問題が偏っただけで「集中が切れた」と誤診**していた
- **1けた − 1けた で「くり下がり あるものだけ」**を選ぶと1問も作れず白紙になっていた
  （原理的に起きない組み合わせ。ひかれる数を2けたに上げるようにした）

作れる種類が少ない単元（既定の設定）: 円と球・円の面積・場合の数が各22種類、円周が33種類。
図形の紙は1枚に10〜12問なので実用上は足りるが、それ以上を指定すると数を減らして出し、その旨を画面に出す。

### 詰めかたの 検証（1万枚）

| 見たこと | 結果 |
|---|---|
| ④ **実さいに1行増やして「もう入らない」を確かめた** | **1152 / 1250（92.2%）** |
| ④ 幾何で「これ以上入らない」 | 8296 / 10000（83.0%） |
| ①②③ はみ出し・文字切れ・重なり | 104 / 10000（1.0%）。待ち時間を伸ばした1200枚では 7件（0.6%）に減り、
  手で再現した分は**描画途中を測った計測の取りこぼし**だった |

直したもの:

- `問題の数` に **`おまかせ` が無く**、一度数を選ぶと二度と自動に戻せなかった
- 入る数を**選択肢（10問・15問…）に丸めて**いて、数問ぶん無駄にしていた
- 入る数を**列の倍数に切り下げて**いた（`floor(i/cols)*cols`）
- **最後の1行を試していなかった**ので、あと1〜2問入るのに止まっていた
- `1行の数` を3列に固定すると**式が横にはみ出す**（描いてから測って減らすようにした）
- **4けた×4けたのひっ算**で部分積が4段になり、答え欄の高さが足りず 15.9mm はみ出していた

これで「これ以上入らない」の実測率は **56.7% → 92.2%** に上がった。
残りは1〜2問の差で、行の高さが中身で変わるため幾何では読みきれない分。

## 色について

棒はすべて藍1色。出来ぐあいを色で表すと（緑・黄・赤）、色の見え方によって
